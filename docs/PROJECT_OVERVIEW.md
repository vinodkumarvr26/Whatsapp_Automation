# Project Overview

## Product Goal

NexChat aims to provide teams with a robust platform for automating WhatsApp conversations, managing leads, routing conversations, and delivering measurable customer engagement workflows.

## Architectural Intent

The platform is planned as a modular monorepo with clear boundaries between:

- frontend experience
- backend APIs
- shared domain models and utilities
- infrastructure and deployment concerns

## Non-Functional Goals

- scalability
- security
- clean code structure
- maintainability
- observability
- production readiness
